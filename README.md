# Lernspiele

Interaktive Lernspiele für die Grundschule (Klasse 3/4).

**Startseite für die Kinder:** https://gidonya.github.io/Lernspiele/

## Aufbau

Jedes Spiel liegt in einem eigenen Ordner unter seinem Fach und besteht aus einer `index.html`.
Neue Spiele werden zusätzlich als Kachel auf der Startseite (`index.html`) eingetragen.

```
index.html              Startseite mit allen Fächern
deutsch/
  tortenklau/           Lesespur mit Suchbild „Der Tortenklau“ (Klasse 4)
mathe/
hsu/
```
